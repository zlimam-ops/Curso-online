Desarrollo Web: HTML, CSS y JavaScript

Módulo 1: HTML, la estructura

HTML (HyperText Markup Language) describe el contenido de una página mediante etiquetas como <h1>, <p>, <img> y <a>. Los encabezados van de h1 a h6. Los hipervínculos usan el atributo href. Referencia: MDN: HTML.

Módulo 2: CSS, el estilo

CSS controla colores, tipografía y distribución. Por ejemplo, background-color cambia el color de fondo y display:flex alinea elementos. Referencia: MDN: CSS.

Módulo 3: JavaScript, el comportamiento

JavaScript se ejecuta en el navegador y permite reaccionar a eventos. Tipos de datos básicos: string, number y boolean. Para seleccionar un elemento por su id se usa document.getElementById(). Referencia: MDN: JavaScript.
